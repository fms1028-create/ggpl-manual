そもそもGitHubって何？

まずここを読んでからステップに進もう

GitHubは、自分のコード（HTMLやプログラムなど）をインターネット上に保存・公開できるサービスです。

「Googleドライブ」のコード専用版、みたいなイメージ！

💾
バックアップ

コードをクラウドに安全に保存

🌐
公開（Pages）

HTMLファイルをサイトとして公開

👥
共有・共同作業

チームで同じコードを管理

📌 このマニュアルでやること
ターミナル（黒い画面）にコマンドを入力して、自分のファイルをGitHubにアップ → URLで公開できる状態にします！
1

STEP 1｜事前準備を確認する

まずターミナルを開いて、必要なツールが入っているか確認しよう

ターミナルを開いたら、以下のコマンドを入力してEnterを押してみよう。

ターミナル
# gitが入っているか確認
$ git --version
git version 2.39.3

# GitHub CLIが入っているか確認
$ gh --version
gh version 2.40.0

# GitHubにログインしているか確認
$ gh auth status
✓ Logged in to github.com account あなたのID
✅ 上のように表示されればOK！
バージョン番号が出ればインストール済みです。数字は多少違ってもOK。
⚠️ 「command not found」と出たら？
gitやghがインストールされていません。
git：https://git-scm.com からインストール
gh：https://cli.github.com からインストール

ログインしていない場合は以下のコマンドでログインできます：

ターミナル
$ gh auth login
? What account do you want to log into? GitHub.com
? How would you like to authenticate? Login with a web browser
✓ Authentication complete!
2

STEP 2｜GitHubにリポジトリを作る

「リポジトリ」＝ファイルを入れる箱のこと。まず箱を作ります！

以下のコマンドを入力するだけで、GitHubにリポジトリ（箱）が自動で作られます。

「my-project」の部分は好きな名前に変えてOK！

ターミナル
# --public = 誰でも見られる公開設定
$ gh repo create my-project --public

✓ Created repository あなたのID/my-project on GitHub
https://github.com/あなたのID/my-project
📌 --public と --private の違い
--public：誰でも見られる（GitHub Pagesで公開するならこちら）
--private：自分だけが見られる（非公開にしたいとき）

コマンド実行後、GitHubのブラウザで確認するとこんな画面になります👇

リポジトリはまだ空です

次のステップでファイルをアップロードします！

3

STEP 3｜ファイルをアップロードする

ファイルをGitHubに送る作業です。順番通りにコマンドを入力しよう！

全部で5つのコマンドを順番に実行します。一つずつ確認しながら進もう！

ターミナル
# ① アップしたいフォルダに移動する
$ cd ~/Desktop/my-project
# 　↑ デスクトップの「my-project」フォルダに移動

# ② gitの管理をスタートする（フォルダ内で1回だけ実行）
$ git init
Initialized empty Git repository in ~/Desktop/my-project/.git/

# ③ GitHubと紐付ける
$ git remote add origin https://github.com/あなたのID/my-project.git

# ④ 全ファイルを「送る準備」にする
$ git add .
# 　↑ 「.」はフォルダ内の全ファイルという意味

# ⑤ 「なんのファイルを送るか」メモをつける
$ git commit -m "最初のアップロード"
[main (root-commit)] 最初のアップロード
1 file changed, 100 insertions(+)

# ⑥ GitHubに送信！
$ git push -u origin main
✓ Branch 'main' set up to track 'origin/main'.
📌 各コマンドの意味
git init このフォルダをgitで管理し始めます、という宣言
git add . フォルダの中の全ファイルを「送る荷物リスト」に追加
git commit 荷物をまとめて箱詰めして、メモを貼る作業
git push 箱をGitHubに発送！ここで初めてネットに上がります

pushが完了すると、GitHubのページにファイルが表示されます👇

⬛
あなたのID / my-project
📁 あなたのID / my-project Public
🕐 最初のアップロード 3分前 ↓ Code
📄 Name Message Updated
📄 index.html 最初のアップロード just now
🎨 style.css 最初のアップロード just now
⚠️ 2回目以降のアップ（ファイルを更新したとき）
2回目からは git init と git remote add は不要！
git add . → git commit -m "メッセージ" → git push の3つだけでOK！
4

STEP 4｜GitHub Pagesで公開する

HTMLファイルをURLで誰でも見られるサイトとして公開します！

コマンド1行で、GitHub Pagesを有効化できます。

ターミナル
# GitHub Pagesを有効にする（mainブランチのルートを公開）
$ gh api repos/あなたのID/my-project/pages \
  --method POST \
  --input - <<'EOF'
{"source":{"branch":"main","path":"/"}}
EOF

✓ Pages enabled!
"html_url": "https://あなたのID.github.io/my-project/"

GitHubの設定画面でも確認できます（Settings → Pages）👇

⬛

⏱️ 公開までのタイムライン
設定後 1〜3分 でURLが有効になります。すぐ開けなかったら少し待ってから試してみよう！
📌 公開URLのルール
https://あなたのID.github.io/リポジトリ名/
※ リポジトリ名が「my-project」ならURLも「my-project」になります

📖 用語集｜わからない言葉はここで確認

リポジトリ
ファイルを管理する「プロジェクトの箱」。GitHubではリポジトリ＝プロジェクトの単位です。1つのサイトや1つのアプリで1つ作るのが基本。
git init
「このフォルダをgitで管理しますよ」という宣言コマンド。フォルダの中に「.git」という隠しフォルダができます。最初の1回だけ実行すればOK。
git add
「このファイルをGitHubに送る荷物リストに追加する」コマンド。git add .で全ファイルを一気に追加できます。
git commit
「荷物をまとめて箱詰め＋メモを貼る」作業。-m の後に「何を変えたか」を日本語でメモしておくと後でわかりやすい。
git push
「箱をGitHubに発送する」コマンド。これを実行して初めてGitHubのサイト上にファイルが現れます。
branch
コードの「作業ルート」のこと。デフォルトは「main」。今回はmainブランチだけ使えばOK！
GitHub Pages
GitHubのリポジトリにあるHTMLを、Webサイトとして無料公開できる機能。https://ユーザーID.github.io/リポジトリ名/ というURLが発行されます。
gh CLI
GitHubをターミナルから操作するための公式ツール。ブラウザを開かなくてもリポジトリ作成やPages設定ができて便利！

🎉 全体の流れまとめ

①gh repo create でリポジトリ作成
②git init で管理開始
③git remote add で紐付け
④git add . で準備
⑤git commit でメモ付き箱詰め
⑥git push で送信！
⑦GitHub Pages で公開🌐

2回目以降は ④〜⑥ の3ステップだけでOK！慣れたらすぐできるようになるよ💪
