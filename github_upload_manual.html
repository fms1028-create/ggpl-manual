GitHubって何？

GitHubは、コード（HTMLやプログラムなど）をインターネット上に保存・公開できるサービスです。「Googleドライブのコード専用版」みたいなイメージ！

💾
バックアップ

コードをクラウドに安全保存

🌐
Web公開

HTMLをサイトとして公開

👥
チーム共有

みんなで同じコードを管理

📌
このマニュアルでやること 黒い画面（ターミナル or コマンドプロンプト）にコマンドを打って、ファイルをGitHubにアップ → URLで誰でも見られる状態にします！
🖥️
STEP 1
黒い画面を開いて
準備を確認しよう

まず「黒い画面」を開きます。MacとWindowsで名前と開き方が違います👇

🍎 Macの場合
「ターミナル」

⌘（コマンド）+ スペースを押す
→「ターミナル」と入力 → Enter

または「アプリケーション → ユーティリティ → ターミナル」

🪟 Windowsの場合
「コマンドプロンプト」

Windowsキー + R を押す
→「cmd」と入力 → Enter

またはスタートメニューで「コマンドプロンプト」と検索

✅
ターミナルとコマンドプロンプト、コマンドは同じ！ 名前が違うだけで、git や gh のコマンドはMacでもWindowsでもまったく同じです。

黒い画面が開いたら、以下を入力してEnterを押してみよう（準備確認）：

ターミナル（Mac）/ コマンドプロンプト（Windows）
# ① gitが使えるか確認
$ git --version
git version 2.39.3 ← こんな感じの数字が出ればOK！

# ② GitHub CLIが使えるか確認
$ gh --version
gh version 2.40.0 ← こんな感じの数字が出ればOK！

# ③ GitHubにログインしているか確認
$ gh auth status
✓ Logged in to github.com account あなたのID
⚠️
「command not found」と出たらインストールが必要！ git → https://git-scm.com（Mac / Windows両対応）
gh → https://cli.github.com（Mac / Windows両対応）
🪟 Windowsの方：インストール後はコマンドプロンプトを再起動してね！
📦
STEP 2
GitHubに「箱」を作る
（リポジトリを作成）

リポジトリ＝ファイルを管理する「プロジェクトの箱」のこと。まずGitHub上に空の箱を作ります。

「my-project」の部分は好きな名前に変えてOK！

ターミナル（Mac）/ コマンドプロンプト（Windows）
# --public = 誰でも見られる公開設定（GitHub Pagesに必要）
$ gh repo create my-project --public

✓ Created repository あなたのID/my-project on GitHub
https://github.com/あなたのID/my-project
📌
--public と --private の違い --public誰でも見られる（ページ公開したいならこちら）
--private自分だけが見られる（非公開）

コマンドを実行するとGitHubにこんな画面が作られます👇

⬛
あなたのID / my-project
Public
📭

箱（リポジトリ）ができた！

まだ空っぽ。次のステップでファイルを送ります

🚀
STEP 3
ファイルをGitHubに送る

ここが一番大事！4つのコマンドを順番に入力するだけです。

①
cd フォルダのパス
📂 アップしたいフォルダに移動する。例：cd ~/Desktop/my-project
②
git init
🏁 「このフォルダをgitで管理しますよ」という宣言。最初の1回だけ実行すればOK！
③
git remote add origin URL
🔗 このフォルダとGitHubの箱を「紐付け」する。URLはSTEP2で表示されたURLを使う
④
git add .
📋 全ファイルを「送る荷物リスト」に追加。.（ドット）は「全部」という意味
⑤
git commit -m "メッセージ"
📦 荷物をまとめて箱詰め＋メモを貼る作業。メッセージは日本語でOK！例：「最初のアップロード」
⑥
git push -u origin main
📤 箱をGitHubに発送！ここで初めてGitHubにファイルが届きます

全コマンドをまとめるとこんな感じ👇

ターミナル（Mac）/ コマンドプロンプト（Windows）
# ① フォルダに移動
$ cd ~/Desktop/my-project

# ② git管理スタート（初回のみ）
$ git init
Initialized empty Git repository ...

# ③ GitHubの箱と紐付け（初回のみ）
$ git remote add origin https://github.com/あなたのID/my-project.git

# ④ 全ファイルを荷物リストに追加
$ git add .

# ⑤ 箱詰め＆メモ付け
$ git commit -m "最初のアップロード"
[main] 最初のアップロード

# ⑥ GitHubに発送！
$ git push -u origin main
✓ Branch 'main' set up to track 'origin/main'.
🔁
2回目以降（ファイルを更新したとき）は3つだけ！ ② git init と ③ git remote add は不要。
git add . → git commit -m "変更内容" → git push の3ステップだけでOK！

pushが成功するとGitHubにファイルが表示されます👇

⬛
あなたのID / my-project
🕐 最初のアップロード 2分前 ↓ Code
NameCommit messageUpdated
📄 index.html 最初のアップロード now
🎨 style.css 最初のアップロード now

STEP 4
GitHub Pagesで
サイトとして公開する

HTMLファイルを誰でもアクセスできるURL付きのWebサイトとして公開します！コマンド1発でOK。

ターミナル（Mac）/ コマンドプロンプト（Windows）
# GitHub Pagesを有効にする
$ gh api repos/あなたのID/my-project/pages \
  --method POST \
  --input - <<'EOF'
{"source":{"branch":"main","path":"/"}}
EOF

✓ Pages enabled!
"html_url": "https://あなたのID.github.io/my-project/"
⏱️
公開まで1〜3分かかります 設定直後はまだ開けないことがあります。少し待ってからURLにアクセスしてみよう！
📌
公開URLのルール https://あなたのID.github.io/リポジトリ名/
⬛
Settings → Pages
🎉 Your site is live at https://あなたのID.github.io/my-project/

Source

Branch: main Folder: / (root) Save

用語集
わからない言葉はここで確認
ターミナル
Macの黒い画面。コマンドを入力してパソコンを操作する場所。⌘+スペース→「ターミナル」で開く。
コマンドプロンプト
Windowsの黒い画面。ターミナルのWindows版。Win+R→「cmd」で開く。コマンドは同じ！
リポジトリ
ファイルを管理する「プロジェクトの箱」。GitHubではリポジトリ＝プロジェクトの単位。
git init
「このフォルダをgitで管理します」という宣言。最初の1回だけ実行すればOK。
git add .
全ファイルを「送る荷物リスト」に追加。ドット（.）は「全部」という意味。
git commit
荷物をまとめて箱詰め＆メモを貼る作業。-m の後にメモ（日本語OK）を書く。
git push
箱をGitHubに発送！これを実行して初めてGitHub上にファイルが届く。
GitHub Pages
HTMLを無料のWebサイトとして公開できる機能。URLが自動で発行されて誰でもアクセスできる。
